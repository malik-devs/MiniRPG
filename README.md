# 🎮 MiniRPG

A small Console RPG game built with **C# and .NET 8**.

MiniRPG is a learning project created to practice **Object-Oriented Programming (OOP)**, classes, inheritance, enums, collections, and organizing a C# project into multiple systems.

## ✨ Features

* 👤 Create your own player
* ⚔️ Turn-based combat system
* 👾 Multiple enemies with different levels and rewards
* 📈 Player XP and leveling system
* ❤️ Health system
* 💰 Gold and rewards
* 🎒 Inventory system
* 🧪 Health Potions
* 🏪 Shop system
* 🧩 Enemy Factory
* 📊 Player statistics
* 🗂️ Organized project structure

## 🛠️ Technologies

* **.NET 8**

## 🎮 How to Run

### Requirements

* .NET 8 SDK
* Visual Studio 2022 or another C# IDE

### Run

Clone the repository:

```bash
git clone https://github.com/malik-devs/MiniRPG.git
```

Navigate to the project:

```bash
cd MiniRPG
```

Run the game:

```bash
dotnet run
```
